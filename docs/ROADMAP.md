# Automation Studio Roadmap

Our vision is to build the ultimate open-source Automation Operating System.

## Completed Milestones
- [x] **EPIC-1 to EPIC-4**: IDE Shell, Runtime Engine, Debugging, and Rich Reporting.
- [x] **EPIC-5 & 5.1**: Plugin Engine, Marketplace infrastructure, and SDK decoupling. (Released in v0.2.0 Preview)

## Upcoming Milestones

### EPIC-6: Recorder & Inspector Platform (In Progress)
- Browser, Desktop, and OCR Element Inspectors.
- Event Recording, Action Capture, and the Smart Object Repository.
- Code Generation engine.

### EPIC-7: Playwright Framework Integration
- Official plugin for Web Automation.
- Network interception, trace viewing, and storage state management.

### EPIC-8 & EPIC-9: Desktop & Vision/OCR Frameworks
- Official plugins for Windows Desktop UI automation and Vision visual automation via OpenCV/Tesseract.

### EPIC-10: API Framework
- REST, GraphQL, and gRPC execution and assertions.

### EPIC-11: AI Platform
- LLM-assisted self-healing locators.
- Natural language to script generation.
- Visual validation using Vision models.

### EPIC-12: Enterprise Platform
- RBAC, Secrets Management, Remote Execution grids, and CI/CD pipelines.
