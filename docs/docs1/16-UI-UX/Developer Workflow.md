# Developer Workflow

1.  Create Project
2.  Configure Bitwarden
3.  Record or Generate Script
4.  Review generated Python
5.  Refactor into Page Objects
6.  Execute Scenario
7.  Debug failures
8.  Publish Reports
9.  Upload Xray Results

Design Goals - ≤3 clicks to start recording - Live object inspection -
Keyboard-first navigation - Git-native workflow
