# Product Vision

## Mission

Build a developer-first automation platform inside VS Code that
generates maintainable Python instead of proprietary XML.

## Objectives

-   Support Vision, Desktop, Playwright and Mainframe.
-   Human-readable source code.
-   Git-native.
-   AI-assisted, not AI-dependent.
-   Enterprise integrations (Bitwarden, Jira/Xray).
-   First-class debugging and reporting.

## Non-goals

-   No low-code workflow designer.
-   No proprietary runtime language.
-   No vendor lock-in.
