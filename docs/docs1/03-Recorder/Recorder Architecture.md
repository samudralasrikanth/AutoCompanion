# Recorder Architecture

## Flow

Input Events ↓ Recorder Engine ↓ Action Graph ↓ Optimizer ↓ Python
Generator ↓ Editor

Recorded Events - Mouse click - Double click - Keyboard - OCR capture -
Screenshot - Wait - Annotation

Generated Output - Python script - Selector JSON - PNG anchor images -
Metadata

Future Enhancements - Timeline editor - Action merge - Undo/Redo - AI
naming - Assertion suggestions
