# Desktop Automation Framework (DAF) v2

The AI-native automation engine for legacy applications.

## Architecture

Unlike commercial tools, DAF exposes a programmable SDK, a modern plugin system, and an AI-first execution model.

- **Vision Engine**: OpenCV and EasyOCR pipeline for robust control detection.
- **Locator Engine**: Multi-strategy locators (OCR, Image, Anchor, Relative, AI).
- **Runtime**: Resilient execution pipeline with self-healing and recovery rules.
- **Input Engine**: Windows/Citrix level hardware inputs and absolute positioning.

## Getting Started

```bash
pip install -e .[dev]
```
